# 2026-10-23

## 修复：左右拖入同一目录时清单为空 / 预览区无动画 / 「刷新对比」像没反应

根因：
- 两侧同一目录时所有动作状态都是 `same`，`transferable_files` 为空；`ActionDiffPanel` 默认过滤「待更新」把清单过滤成 0 行 → 没有当前动作 → `action_selected` 不发出 → 预览区不加载任何序列帧。
- 「刷新对比」确实执行了扫描，但结果与上次完全一致（清单空、状态文字相同），所以看起来毫无反应。
- 附带隐患：扫描进行中再次请求刷新会被 `_scan_in_progress` 直接吞掉，导致界面停在旧目录的结果。

改动：
- `views/action_diff_panel.py`：新增 `_relax_filter_when_empty()`（「待更新」为空但有动作时自动切「全部」并打提示）、`_restore_current()`（重扫后停在原动作，显式触发预览联动）、`_current_action_path` / `_auto_relaxed` 状态；出现待更新时自动切回「待更新」。
- `controllers/main_controller.py`：扫描完成状态区分「两侧为同一目录 · 仅预览」「未识别到动作序列目录」「共 N 个动作 · M 个待更新」；新增 `_pending_refresh` 队列（`_run_pending_refresh()`）补跑被吞掉的刷新。
- `tests/test_ui_workflow.py`：新增 5 个回归用例（已一致仍可见、自动放宽后切回、重扫保持选中、同目录出动画帧、扫描中刷新补跑）。测试 111 passed。
