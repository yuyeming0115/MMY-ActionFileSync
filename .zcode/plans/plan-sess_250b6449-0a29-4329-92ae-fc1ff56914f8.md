# 「冗余帧扫描」功能实施计划

## 需求与判定规则

在应用内新增一个独立工具：一次性扫描整个目录树（如 `E:\XYJProject\美术资源\动画序列帧\角色输出图`），找出「多余方向 × 非保留动作」的冗余帧，确认后整体移动到备份目录。

**判定规则（默认值，可在界面编辑并持久化）：**
- 冗余方向集合 = `{E, N, S}`；保留动作集合 = `{idle, run}`（按你的更正：E/N/S 下除 idle 和 run 以外的动作算多余，例如 `E/attack`、`S/hurt` 都会被扫出）。
- 匹配方式：任意深度的目录树中，**含图片文件的叶子目录 = 动作目录**（与 `scan_service.py` 的 sequence 判定一致）；其**父目录名 ∈ 冗余方向集合**（casefold 不敏感）且**动作目录名 ∉ 保留动作集合** → 整个动作目录判为冗余。
- 无方向层（父目录不是方向名，如 `角色/idle/`）的动作不参与判定，永不误报；`.svn` 等隐藏目录跳过；扫描根目录本身不作为动作候选。

## 架构方案（沿用现有模式）

新增 4 个文件 + 修改 3 个文件，完全复用现有 Worker(QThread) + Service + QDialog 模式。冗余扫描**不做文件哈希**（只看目录名/文件数/大小），比主对比扫描快得多。

### 新增文件

**1. `services/redundancy_service.py`** — 纯业务逻辑
- `RedundancyItem` dataclass：`relative_path`（posix）、`direction`、`action_name`、`frame_count`、`file_count`（含 GIF）、`total_bytes`
- `RedundancyService.scan(root, redundant_directions, keep_actions, cancel_token) -> list[RedundancyItem]`：`os.walk` 遍历，隐藏目录跳过，`CancellationToken` 可取消（抛 `ScanCancelledError`，仿 `scan_service.py`）
- `RedundancyService.move_to_backup(root, backup_root, items, callbacks, cancel_token)`：按 `<备份根>/<原相对路径>` 结构用 `shutil.move` 整目录移动（跨盘安全）；目标重名自动加 `_1`/`_2` 后缀**绝不覆盖**；移动前用 `_safe_join` 式 resolve+`relative_to` 校验防越界（仿 `transfer_service.py:158`）；逐项目回调进度，可取消

**2. `workers/redundancy_worker.py`** — 仿 `scan_worker.py`
- `RedundancyScanWorker`：`finished(list)/failed(str)/progress(int)` 信号
- `RedundancyMoveWorker`：`item_finished(name, ok, error)/completed(moved, failed)/failed(str)` 信号

**3. `views/redundancy_dialog.py`** — 仿 `transfer_preview_dialog.py` 的模态工具对话框，**自包含运行自己的 Worker**（不污染主对比流程；`main_controller` 只负责打开它）
- 顶部：扫描目录选择（复用 `DropPathEdit` 拖入 + 浏览，默认填当前来源路径）；规则两行输入：「冗余方向（逗号分隔）」默认 `E, N, S`、「保留动作（逗号分隔）」默认 `idle, run`
- 中部：`QTreeWidget` 结果表，**动作目录粒度**（移动以目录为单位，不按帧拆分）：勾选 | 方向 | 动作 | 帧数 | 大小 | 相对路径；支持全选/全不选；汇总标签「已选 N 个动作 · M 帧 · 大小」
- 底部：备份目录选择（默认空，持久化）+「移动到备份目录」主按钮 + 关闭；移动前 `QMessageBox.question` 二次确认；完成后移除已移动行、报告失败项
- 持久化（QSettings）：`redundancy/directions`、`redundancy/keepActions`、`redundancy/backupRoot`、列宽 `redundancyDialog/columnWidths`
- 说明：规则输入做成可编辑默认值而非写死，是为了不同项目约定（如 8 方向）时不用改代码；默认值即你定的规则

### 修改文件

**4. `views/source_target_bar.py`** — 工具栏「清空」旁加「冗余帧扫描」按钮 + `redundancy_scan_requested = Signal()`；`set_busy()` 中随 `clear_button` 一起禁用，避免与主扫描并发 IO

**5. `controllers/main_controller.py`** — 连接信号 → `_open_redundancy_scan()`：传入当前来源路径打开对话框；对话框关闭时若发生过移动且扫描根 == 来源根，自动触发 `refresh_compare()` 保证清单与磁盘一致

**6. `tests/test_redundancy_service.py`（新增）+ `tests/test_ui_workflow.py`（追加）** — unittest + 真实临时目录风格（仿 `test_path_matcher.py` / `test_ui_workflow.py`，offscreen Qt）
- Service 测试：E/N/S×run 被扫出、E/idle 与 W/attack 保留、`e/run` 小写命中、嵌套 `角色名/E/hurt` 命中、无方向层跳过、GIF 计数、`.svn` 跳过、取消中断；移动：结构保留、重名加后缀不覆盖、越界拒绝、取消
- UI 测试：临时目录构造 `角色/E/run`、`角色/E/idle`、`角色/W/attack` → 扫描后结果仅 1 行（E/run）→ 走移动流程（QTimer 模态确认技巧）→ 断言文件已移到备份目录且原位消失

**7. 文档** — `README.md` 补充功能说明与安全边界（「仅在确认后移动到备份目录，不删除、不影响 SVN 目标侧」）；`开发文档/MMY-ActionFileSync_UI重构开发计划.md` 末尾追加 2026-09-28 变更记录
